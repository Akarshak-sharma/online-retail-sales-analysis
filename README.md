# Online Retail Sales Analysis

## 📌 About the Project

This is a hands-on Python and Pandas project based on the Online Retail
transaction dataset.

The goal of this project is to learn Python, Pandas, data cleaning,
exploratory data analysis (EDA), and extracting useful insights from
real-world retail data.

## 🛠️ Technologies Used

- Python
- Pandas
- Google Colab
- Jupyter Notebook

## 📊 Dataset

The project uses the Online Retail dataset from the UCI Machine Learning
Repository.

The dataset contains online retail transactions including:

- Invoice number
- Product/Stock code
- Product description
- Quantity
- Invoice date
- Unit price
- Customer ID
- Country

## ✅ Work Completed

- Loaded the Excel dataset using Pandas
- Inspected dataset structure
- Analyzed rows and columns
- Checked missing values
- Investigated cancelled transactions
- Investigated negative quantities
- Created a cleaned sales dataset
- Created a Revenue column
- Analyzed revenue statistics
- Analyzed products by quantity sold
- Analyzed products by revenue
